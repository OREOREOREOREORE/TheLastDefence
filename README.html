Prerequisite

Before you can run the game, make sure your Node.js is of version >= 23.6.0

As this project uses Typescript as well as SQLite modules

Installation Instructions

  1. Run 
    npm install
    . This should install all the required dependencies and build the project.
  2. Run 
    node src/server/index.ts
  3. Open the browser and navigate to http://localhost:8000. You should see a login page.
  4. You can register a new account with your desired credentials. You may login afterwards

Note: For the game description and instructions you can see it after login and pressing the About button.
