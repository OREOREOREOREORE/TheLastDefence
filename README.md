# Instructions

## Prerequisite

Before you can run the game, make sure your Node.js version is `>= 23.6.0`.

As this project uses TypeScript as well as SQLite modules.

## Installation Instructions

1. Run `npm install`. This should install all the required dependencies and build the project.
2. Run `node src/server/index.ts`.
3. Open the browser and navigate to [http://localhost:8000](http://localhost:8000). You should see a login page.
4. You can register a new account with your desired credentials. You may log in afterwards.
5. After you hit the Start button, you will be put into an existing game
   room with another player, or a new room if there is no available room.
   For testing, you will need to open another browser window in private
   mode and login as another user to join the existing game room you just
   created. Hit the Ready button when you're ready.
6. The game will start automatically when both players are ready.

Note: For the game description and instructions, you can see it after login and pressing the About button.
